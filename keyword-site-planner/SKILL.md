# 关键词建站框架

用户已提供一个关键词，要求围绕该词规划如何建站。按以下阶段输出完整方案。

## 核心原则

- **一个关键词一个页面**：每个独立搜索需求对应一个独立页面
- **首页打核心词**：如果用户给的是核心词（搜索量最大的词），首页就打这个词；如果是长尾词，首页可以打同类中最热的一个词
- **横向拓展**：上线后不断加内页打更多相关长尾词，首页不变
- **新词双线操作**：新词出现时，既在老站加内页，也注册新域名上新站去打

## 阶段一：关键词竞争确认

用以下方法快速确认竞争情况：

1. **谷歌趋势**：打开 https://trends.google.com
   - 时间选最近 12 个月，看曲线趋势
   - 之前接近 0 最近才冒头 → 新词，竞争极低
   - 跟已知搜索量的词对比，推算该词的搜索量

2. **谷歌搜索前 10 名分析**：
   - 在 https://www.google.com 搜索该词
   - 看前 10 名中：首页 vs 内页比例、有无 DA 80+ 大站、页面质量

3. **allintitle 查供应量**：
   - 搜索 `allintitle: "关键词"`，记下结果数
   - 如有搜索量数据 → KGR = 结果数 ÷ 月搜索量，< 0.25 为蓝海

4. **确认搜索意图**：搜出来是工具页多还是教程/问答多？广告位多不多？

## 阶段二：网站结构规划

### 确定网站类型

| 类型 | 说明 | 特点 |
|---|---|---|
| 单页工具站 | 一个在线工具直接解决需求 | 首页即核心页 |
| 多页工具站 | 首页 + 多种功能内页 | 每个内页打一个长尾词 |
| 数据查询站 | 金价/汇率等 | 按日/月/年做独立页面 |
| 内容资讯站 | 工具站 + 博客栏目 | 博客内页拿流量 |

### 输出网站结构（Markdown 表格）

| 页面 | URL | 目标关键词 | 类型 |
|---|---|---|---|
| 首页 | `https://domain.com/` | 核心词 | 首页 |
| 功能A | `https://domain.com/tools/a` | 长尾词A | 工具内页 |
| 功能B | `https://domain.com/tools/b` | 长尾词B | 工具内页 |
| 博客 | `https://domain.com/blog/` | 内容词 | 博客 |
| FAQ | `https://domain.com/faq/` | 问答词 | 内容页 |

### 横向拓展建议

基于词根和同类表达列出可拓展的长尾词方向。例如 photo 还可以用 image、picture、pic、img 等表达。

## 阶段三：页面 SEO 方案

对首页 + 1-3 个关键内页，逐个给出：

```
URL:
Title 建议:
Meta Description 建议:
H1 建议:
Schema 类型（参考 https://schema.org）:
页面内容模块:
  1. 核心功能/内容区
  2. 特色功能介绍（3-5 点）
  3. 使用教程/操作步骤
  4. 示例/案例展示
  5. FAQ 部分
内部链接: 指向哪些相关页面
```

## 阶段四：建站执行方案

### 技术选型建议

| 类型 | 推荐技术栈 | 部署 |
|---|---|---|
| 简单工具站 | 纯前端 HTML/CSS/JS | Vercel / Cloudflare Pages |
| 多页工具站 | Next.js / Nuxt.js SSG | Vercel / Cloudflare Pages |
| 数据查询站 | Workers + KV / D1 | Cloudflare |
| 内容资讯站 | WordPress | 传统主机 |

### 输出物

- URL 完整列表（标注每个页面的用途和目标关键词）
- 域名建议（最好包含核心关键词）
